# 项目交互与输出规则 (Project Interaction & Output Rules)

## 风格录入与特征提取铁律（严禁提取示意图具体画面内容）
- **严禁将参考图/示意图的具体画面内容提取为风格特征**：
  - 无论通过任何 Skill（如 `style-library-importer`、`tweet-style-importer` 等）或直接操作新增/录入画风或摄影风格时，**绝对禁止**将参考图、示例图、推文配图中的具体画面内容（包括主体人物、性别外貌、服装穿搭、动作姿势、具体动植物、道具、具体场景建筑与情节叙事）写入风格特征（traits）。
  - **严禁出现的违规特征反例**：“白色棉麻长裙的年轻女性”、“黑色短发”、“侧身回眸”、“大面积黄色花田”、“湖海远山”、“咖啡杯”、“雨伞”等。
  - **特征描述只允许包含纯粹的艺术视觉语言**：
    1. 媒介与材质（如钢笔线描、水墨晕染、胶片颗粒、油画肌理、矢量平涂）；
    2. 色彩倾向与光影质感（如高饱和通透、日系青蓝冷调、暖调复古、侧逆光光晕）；
    3. 空间与景深机制（如浅景深大光圈虚化、平铺留白、空气感、极简构图）。
  - **主题解耦原则**：画风特征必须对任意后续主题（如“宇航员在月球”、“老人在雨中散步”、“猫咪在厨房”）完全透明无侵入。画面中的一切主体、服饰与环境必须 100% 由用户输入的画面主题（Theme）定义。
