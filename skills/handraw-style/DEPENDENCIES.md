# 包内资源与外部依赖

## 项目可独立携带的内容

根目录安装入口、各子Skill规范与脚本、风格/图型/颜色目录、参考图和画廊页面均随仓库提供。视频迁入代码、必要字体和许可证随包提供，不要求用户保存开发者的参考项目目录或私有案例工程。

仅阅读画廊与提示词规范时，无需视频运行时。执行图库索引、图像处理和YAML校验等Python工具时，使用`python -m pip install -r requirements.txt`安装Pillow与PyYAML。运行Python脚本要求Python 3.10及以上。安装第三方包需用户明确执行，读取Skill不自动安装。

## 按功能使用外部工具或服务

- 图片生成依赖用户客户端提供的生成工具、模型权限或用户选择的平台；本包不包含生成模型，也不附带账号或密钥。提示词生成可独立完成。
- X推文导入的抓取代码使用网络接口，接口可用性不由本包保证；从网址导入、下载原图属于用户明确发起的任务。既有本地风格库和画廊不需要抓取服务。
- 商业指南批量脚本在明确执行时调用外部服务，密钥从环境变量读取；生成的本地内容不作为Skill必备输入。
- 自建图库是可选用户输入，位置保存为个人配置；既有预设图库不依赖开发者的自建图库目录。用户项目和原始照片同样在本期工程中准备。
- 视频按[视频安装与依赖](skills/handraw-video-producer/references/installation_and_dependencies.md)选择Python包、FFmpeg、浏览器、Node.js和剪映。锁文件保证依赖声明随包提供，不等于依赖二进制也已打包。
- 配音、Flow片段、真实录屏和本期插画按用户确认后的素材清单准备；没有账号/服务/素材时明确报告，不把开发者机器上的能力视为随包能力。
- 火山语音客户端随[handraw-volc-tts](skills/handraw-volc-tts/SKILL.md)提供，使用Python标准库和另行安装的FFmpeg，无需外部CLI项目。TTS及ASR仍需用户服务权限；账户显式提交后保存到仓库外用户配置，Windows当前用户加密，更新Skill保留配置。

## 发布前检查

```powershell
python scripts/audit_release.py --json tmp/release-public-audit.json
```

检查Git当前提交候选，不输出密钥值。配置、缓存、个人工程、视频和凭据按忽略规则排除；已跟踪文件仍会扫描，不因后来加入忽略规则而跳过。安装同步另按文件清单与哈希检查，演示视频不随包下载。

检查范围不包含完整Git历史或远程当前状态；不能用工作区已修复代替已发布提交已修复。公开署名、版权、上游网址及项目主动发布的社群二维码不作为私密配置删除。
