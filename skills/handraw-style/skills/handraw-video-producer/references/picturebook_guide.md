# 绘本视频制作指南 · ST-001

本指南用于“绘本视频、动态绘本、有声绘本”请求。绘本是ST-001单图动画的内部编排，目录仍只有七类；不新增业务预设、组合配方或版式分类。总控确认输出路线后，浏览器与剪映制作Skill均读取此文件。

**明确图型优先：**本指南的无字插画＋独立短句是未指定图型时的默认方案。用户指定图型时必须按[手绘出图规则](image_prompt_rules.md)生成完整图文页；下文的无字素材模板与独立文字配置不覆盖该要求。整页图使用实际画幅与region，不再添加重复文案；图内文字固定，独立旁白字幕另行安排。

## 1. 页面与阅读节奏

默认以《一片叶子的屋檐》的页面结构作为布局参考：

- 暖白或本期选定的纸页背景，四周留白；纸纹可选。
- 完整插画居中，位于画面中上部；短句放在下方纸面上，居中排列。小标题和页码可选，不能挤占故事画面。
- 横版、竖版分别设计插画区域与文字区，默认等比容纳。竖向原图用于横版时保持完整，不为铺满屏幕裁断人物。需要更宽插画时，先在方案中设计对应构图和素材。
- 每页表达一个明确事件或情绪变化。人物身份、画风、色板、光照、故事物件连续；镜头与停留时间服务阅读和实际旁白，不固定页数或每页秒数。
- 故事短句是页面文案；旁白可以更完整。共享字幕使用实际配音时间，独立于页面短句。两者相同且无需重复时，可在方案中选择sidecar字幕；需要画内字幕时另留安全区。不得默默关闭用户指定的字幕。

不默认采用左图右解释、PPT式长段文案或铺满全屏的插画。用户明确选择其他构图时遵从。本案例只提供布局与阅读感参考，不绑定刺猬角色、水彩风格、原故事或旧模板。

## 2. 从方案到素材

遵循[制作阶段](production_stages.md)：方案确认前只设计；确认后准备素材；全部必需画面审查通过再配音、动画、预演或合成。此规则对两条路线、子工程和期内脚本一致。

完整方案逐页记录：镜头ID、事件/情绪、插画内容、准确短句、完整口播、预计阅读时间、图片区域、文字安全区、可选运动、转场、素材来源及输出路线。只改变静态图的缩放不称为人物已表演动作；需要真实姿态变化时，明确相邻故事页的变化，或另行设计适合的已确认分镜。

|输入|格式与准备要求|
|---|---|
|每页完整插画|PNG优先，可解码JPG/WebP；包含场景和主体，不拆sprite；不要烘焙标题、短句、字幕或页码|
|身份/场景参考|需要连续性时交付实际图；先审查再制作后续页，固定脸型、服装、配件和重要物件|
|纸页背景|可用episode.visual.paper纯色，无需额外生成；选纹理时提供实际PNG并检查图层顺序与文字可读性|
|短句/口播|准确文本，保存到方案和脚本；不把配音后SRT误列为前置画面素材|
|环境效果素材|仅在方案选定且实际实现需要时准备透明PNG等；列明区域、遮挡、显示时间与路线支持|

图片尺寸依据插画区最终像素与最大缩放需求决定，不机械要求每张都16:9或全片同尺寸。原件保留，素材归档至本期assets/Sxx/。详见[单图素材准备](shot-materials/ST-001-single-image.md)。

缺图时，方案确认后逐页交付填写完整的可复制提示词、实际参考图、文件名/尺寸/格式、回传位置和审查点，保存work/material-prompts/。以下只作写作结构，正式交付不得残留变量：

```text
绘本第{页}页，完整无字插画，输出{宽×高}PNG。画风{具体线条、笔触、媒介与质感}，色板{具体色值与角色分工}。故事事件{本页具体发生的事}，场景{时间、地点、光照}，角色{已确认身份、服装、道具、姿态与情绪}。保持所附身份参考的辨识特征，相邻页衔接{前后状态}。
构图{主体位置、景别、完整身体与重要物件的安全边界}。这张图后期置于纸页中央，标题和故事短句另行排版，不画纸页UI、标题、文字或字幕。不要裁断{具体部位/物件}，不要添加水印、无关主体或未经设计的物件。
```

提示词按本期手绘风格Skill的参考图隔离规则区分“画风参考”和“角色身份参考”，不把画风参考中的角色复制进新故事。

## 3. 两条路线使用同一页面设计

|项目|浏览器输出web|剪映输出jianying|
|---|---|---|
|基本绘本页|ST-001主图＋纸色＋独立text图层|原生图片＋纸色色底＋可编辑TextSegment|
|轻微运镜|region位置/缩放和透明度关键帧，按帧复算|已适配的位置/缩放/透明度关键帧|
|跨页衔接|按统一时间线配置已实现转场，检查边界|按真实名称/ID写入原生转场，逐页检查主图同轨与时间限制|
|声音/字幕|统一配音、实际字幕、混音，输出MP4|相同配音和字幕来源，音轨分离，交付草稿及素材包，用户手动导出|
|纸纹/圆角/环境|按实际素材和本期实现检查；特效可选|具备素材与原生实现时使用；复杂蒙版、JS、水彩显现不作为默认原生能力|

两条路线可制作相同的核心绘本布局和故事。可选动画不要求完全相同；选定效果无法原生实现时，在方案阶段说明并按[剪映规则](jianying_output_guide.md)处理，不静默去掉效果或自动预渲染。基础绘本页无需用户提供整段生成视频，也不需要白板/Remotion。

## 4. composition-v2配置方法

每页一个ST-001镜头；多页连续覆盖全片。用config.asset、fit=contain、region及可选keyframes设置完整插画，layers记录标题、故事短句等。背景用episode.visual.paper；帧区间采用左闭右开。绘本是编排说明，**没有config.mode=picturebook、通用align=center或独立绘本渲染器开关**。

以下五秒/30fps的横版插画配置只说明已支持字段，不是固定版式；图像路径须换成本期已审查素材：

```json
{
  "asset": "assets/S02/S02_IMG01_v01.png",
  "fit": "contain",
  "region": [0.30, 0.125, 0.40, 0.65],
  "keyframes": [
    {"at_frame": 0, "region": [0.303, 0.130, 0.394, 0.64]},
    {"at_frame": 149, "region": [0.30, 0.125, 0.40, 0.65]}
  ]
}
```

文字使用kind=text、text、region、font_size、weight、color及start_frame/end_frame。当前两条路线的文字按左上位置排布：先按实际字体测量每行宽度，再以`x=(画布宽度-文字宽度)/2`计算归一化region起点；多行短句可分别作为文字图层居中，不用空格凑中心。给测量留余量，避免自动换行影响居中；字体在剪映实际打开后复核。

插画微推必须在最大缩放时仍位于设计区域，不能进入下方故事短句。画内字幕的当前默认区位于画面下部，需把故事短句放在其上方；正式页面检查实际字幕面板遮挡，不只检查文本本身。不同画幅重新计算字号与区域，不机械复制横版坐标。

## 5. 验收与证据边界

同时执行[镜头审查与交付核对](delivery_review.md)。用户指定直接用某项目的图片/整页时，先确认实际文件及版本；裸插画和带纸纹、标题、正文的完整绘本页不是同一种素材。完整原页可按明确需求直接复用，图内文字固定的限制必须说明；默认新故事仍使用无字插画与独立文字。预览卡片要标明素材或完整页面，不把裸插画缩略图当成已经验证的绘本构图。

1. 插画完整、身份连续、上下阅读顺序明确；最大运镜不裁断主体或遮住短句。
2. 标题/短句居中、多行逐行对齐，字号可读；字幕面板与故事文字不相撞。
3. 每页事件与口播一致，停留时间足以阅读；实际配音/SRT对齐，转场不抢走关键阅读时间。
4. 可选环境效果不进入保护区域，雨滴等不误穿屋檐/人物；不把装饰动画称为人物行动。
5. 重复、逆向跳转和重新加载结果一致；成片帧数、时长、完整解码、音频按路线验证。
6. 剪映检查包与安装路径、可编辑文字、关键帧和转场；草稿结构、应用打开、实际导出、审美接受分别记录。
