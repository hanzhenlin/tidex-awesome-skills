# ST-005 · Remotion 动画：素材准备

先执行[共用缺素材规则](README.md)。按本镜需要编排图片、透明PNG、文字、图形与图表；不是固定模板。外部画面素材与制作代码分开。

## 所需素材与格式

|素材|必要性|交付格式|要求|
|---|---|---|---|
|主图/背景/截图|本镜使用时必需|PNG优先；可解码JPG/WebP|区域、清晰度与镜头目的吻合；操作证据使用真实截图|
|透明主体/图标|本镜使用时必需|RGBA PNG|真实透明、固定可见边界与布局锚点|
|标题/标签/讲解内容|使用文字时必需|MD/TXT内容记录，或已审核JSON数据|准确文字，通常后期保留可编辑文本实现|
|图表/关系数据|使用图表时必需|UTF-8 JSON/CSV|值、单位、来源与概念配色明确；不可用虚构数字填缺项|
|字体方案|使用文字时说明|现有本机或随附且有许可的字体名称/可用性|自定义字体加载与文件审查需另核对，不宣称任意字体文件已通用支持|
|本期编排实现|制作阶段产生|默认导出React组件的TSX，必要模块TS/TSX/JS|不是画面素材前置条件；审核全部画面输入后才编写|

纯文字/图形镜头可没有外部图片，不能为了齐备而生成占位图。有数据时先核对真实数据；动画代码不能代替数据来源。

## 文件与配置

图片放`assets/S05/`，实现放`work/S05/Scene.tsx`。最终config片段：

```json
{
  "entry": "work/S05/Scene.tsx",
  "props": {"headline": "先想清楚，再行动"},
  "inputs": ["assets/S05/hero.png", "assets/S05/background.png"],
  "code_files": []
}
```

正式inputs只列实际使用且已审核的文件，保留assets相对路径并用staticFile引用。组件通过useCurrentFrame/useVideoConfig等按帧运行；不使用墙钟、未种子随机或组件自带配音。实际数据可经审核后转入props；不要以为任意CSV会由适配器自动画成图表。

## 缺素材提示词

逐项区分需要生成的视觉资产、需要采集的事实与尚未到制作阶段的实现：

```text
透明插画/图标：为{镜头目的}绘制{具体角色/物件与辨识细节}，采用{本期画风、线条、材质和配色}。输出{宽×高}真实RGBA透明PNG，主体{朝向与姿态}，置于{布局锚点}，预留{运动安全边界}。与实际提供的{身份/场景参考}一致。不要文字、背景、棋盘格、模糊边缘、截断或额外物件。
```

```text
背景/主图：生成{尺寸}的{具体场景}插画，{固定透视、光照、风格和色板}。为{主体卡片/路径/图表区域}保留明确空间；构图{具体分布}。不把后期文字、图表数据或需要独立动画的主体画入背景。输出完整PNG。
```

数据缺失时输出“需补数据”清单，列字段、单位、时间范围、来源与核对要求；不能用图像生成提示词制造事实。界面截图缺失时给真实截图采集步骤。标题/说明缺失时可根据已确认脚本提出文案，事实不明先澄清。

如实现缺失，在素材齐备后输出给AI的制作指令，而非让用户去图片/视频平台生成TSX：

```text
基于已确认S05分镜和审核通过的实际素材，编写默认导出的React组件。画幅、帧率和时长读取镜头配置；用固定帧时间控制{布局、进出场、路径、强调与最终停留}。使用{明确素材路径/props}；保持{锚点、概念配色、可读性}。无付费生成、组件配音、墙钟依赖或未经审核的数据。列出缺少的实现，不静默换效果。
```

## 验收与输出路线

- 检查图片真实像素/透明、文案与图表事实、字体显示、锚点、遮挡和动作入镜。
- 制作阶段检查重复/逆向跳转、素材引用与帧数，不把TSX存在当成动态效果已验证。
- 剪映默认不支持此类型原生；只有用户同意具体镜头后才能预渲染为视频，画面合并不可按原图层编辑。所需视频缓存由制作阶段生成，不要求用户提前交来替代素材。
