# ST-006 · simo 版白板动画：素材准备

先执行[共用缺素材规则](README.md)。该实现按元素描线、文字逐字擦入、图片贴纸擦入；不把任意图片自动变为逐笔矢量。

## 所需素材与格式

|素材|必要性|交付格式|要求|
|---|---|---|---|
|讲解文字与关系图意图|必需|已确认脚本/MD说明；结构关系可用JSON|概念、顺序、标签、箭头含义与配色准确|
|图片贴纸|本镜使用时必需|PNG；需无底时为RGBA PNG|物件完整、风格统一、尺寸/显示区明确；不强制每镜都有图片|
|事实/图表数据|实际使用时必需|JSON/CSV|真实来源、单位、数值，审核后再编排|
|元素场景与绘制节拍|制作阶段生成；用户提供时先盘点|scene JSON或CommonJS导出场景对象的DSL/CJS|elements、files、intervals；编排不能在画面齐备前开工|
|字体与纸色|共享视觉设置|已有Xiaolai字体/许可、具体纸色色值|文字擦入不是字体真实书写笔画|

当前元素类型为rectangle、ellipse、diamond、line、arrow、text、image。SVG/PSD可作为源文件保留，不能直接传入当前贴纸接口；先导出实际PNG并审查。

## 文件与配置

贴纸推荐`assets/S06/coffee.png`，场景推荐`work/S06/scene.json`。config：

```json
{"scene": "work/S06/scene.json", "inputs": ["assets/S06/coffee.png"]}
```

制作阶段可采用如下两元素场景示例（120帧镜头）：

```json
{
  "elements": [
    {"id":"label","type":"text","x":140,"y":100,"width":500,"height":60,"angle":0,"strokeColor":"#242b38","fontSize":44,"lineHeight":1.25,"text":"先想清楚","textAlign":"left","opacity":100},
    {"id":"sticker","type":"image","x":700,"y":240,"width":260,"height":220,"angle":0,"opacity":100,"fileId":"coffee"}
  ],
  "files": {"coffee": {"asset":"assets/S06/coffee.png"}},
  "intervals": [[0,45],[45,105]]
}
```

intervals按元素顺序串行，每元素一个[开始帧,结束帧]，采用镜头局部帧号。image.fileId必须对应files中的真实asset；形状/线条还需固定正整数seed及已支持绘制属性，line/arrow提供局部points。不要内嵌未经审核的dataURL。更多实际字段见[分镜工程](../shot_video_guide.md)。

## 缺素材提示词

没有贴纸也可纯线条/文字讲解；只有方案需要图片而缺失时才交付生成提示词：

```text
生成一张用于白板讲解{具体内容}的{角色/物件}贴纸，{本期手绘线条、强调色与质感}，输出{具体像素}RGBA透明PNG。只画{完整主体、所需姿态、细节}，确保{箭头/标签附近需要的轮廓清晰度}。保持实际参考中的{身份特征}。不要背景、棋盘格、文字、水印、过重阴影、细碎噪点或裁断主体；这是一张图片贴纸，不是自动逐笔矢量文件。
```

缺事实关系/数据：给字段、来源与概念核对清单，不发明关系。缺讲解文字：根据已确认脚本形成准确标签，不交由图像模型写字。

场景文件缺失时，把它记为制作阶段任务；在输入审核后给AI如下指令：

```text
按S06已确认讲解意图和审核通过素材生成simo scene JSON。只用当前支持元素；文字保留准确文案，图片fileId绑定实际assets路径。形状固定seed，线条箭头说明points、颜色与笔宽。elements与intervals一一对应、按整数帧串行；不得先露出未讲到的内容。绘制顺序是{具体概念顺序}，最后留{明确帧数}观察结果。无品牌片尾、自动配音或付费素材调用。
```

## 验收与输出路线

- 图片清晰且alpha真实；文字/箭头含义准确，场景元素与文件引用相符。
- 线条是真实逐笔效果，贴纸是擦入，文字是逐字擦入；三者不混称为人物动作或书法笔画。
- 剪映默认不原生支持；用户同意具体镜头才预渲染，不把逐笔实现硬替换成普通淡入。
