## 缺素材时必须做什么

1. 先盘点本期或用户允许复用的实际文件，记录镜头ID、素材ID、用途、状态、格式及文件名。不能只因文件存在就标注可用。
2. 方案确认前，可列缺项、草拟素材要求；确认后才交付正式生成提示词、制作参考图或准备画面。不要提前配音、编写本期动画、渲染或合成。
3. 对每个缺失且可生成的素材，**必须输出针对本镜的完整提示词**，保存为本期`work/material-prompts/S01.md`等文件；不只让用户“找图/补图”，不只交付泛用模板。
4. 交付包含：镜头与素材编号、内容目的、预计文件名、格式/尺寸/透明要求、中文说明、完整可复制提示词、实际参考图、回传位置及审查点。图像提示词默认中文；Flow等视频为中文说明＋英文生成提示词，用户指定语言时遵从。
5. 本目录花括号内容是写作模板。正式交付必须填写为本期具体主题、角色、场景、画风、色板、构图、动作及负面约束。禁止带未填写变量交给用户。
6. 需要角色/场景参考图时交付实际文件或可打开链接；参考图缺失则先为它建立独立生成任务，不能只提供一个不存在的名字。先生成并审看身份参考，再做动作帧或相邻镜头。
7. 真实录屏、权威数据、用户照片/品牌原件、已有配音实际时间等不能靠提示词补出真实性，改为明确采集清单或索取文件；不能伪造事实、操作记录或字幕时间。
8. 文件回传后做技术检查和实际画面审查，记录`production.json`；外部视频同时用`video_tasks.json`及既有导入/审查流程。全部必需画面输入通过后才进入制作。无需外部图片的镜头也应完成内容/数据盘点，不用占位图凑清单。

## 通用文件规则

- 文件位于本期`assets/`，建议`assets/S01/`按镜头归档；引用为工程相对路径。原件与候选版本保留，文件名包含素材ID和版本，例如`S01_BG01_v01.png`。
- 图片优先PNG；完整图可使用可解码JPG/WebP，按实际引擎转换并保留原件。透明主体统一交付带真实alpha的PNG，不能以棋盘格/白底冒充透明。不把SVG/PSD当作当前可直接输入的图片；保留源文件并导出PNG。
- 尺寸根据全片画幅与最终显示区域确定，例如横版1920×1080、竖版1080×1920；放大/裁切镜头须给足实际像素与动作安全边界。不要把所有插画强制做成全屏背景。
- 视频优先本地MP4（H.264画面，需原声时AAC），实际解码后检查；MOV/WebM等先核查并必要时无损保留原件、另做兼容版本。不是改扩展名。不默认支持透明视频。
- JSON使用UTF-8有效JSON、无注释/尾逗号；数据CSV使用UTF-8且有字段、单位、来源。字幕SRT使用UTF-8、有效编号/时间/文本，不伪造配音对齐时间。正式字幕显示、声音和输出方式仍为共享设置。
- 图像文字与字幕分开：未指定图型且要求可编辑标题、标签时后期制作。指定图型则沿用原图型的图文出图规则，生成完整图文画面并逐字检查；图内文字不可独立编辑，合成时不重复添加相同文案。实际旁白字幕仍独立。
- 图片序列`hold_frames`、显示区间和动作节拍以整数帧记录；镜头配置中使用局部帧号，声音/共享字幕使用全片帧号。文件顺序不能只依赖目录排序。

## 提示词任务单模板

```text
镜头：S01 / ST-...
缺失素材：S01_BG01
用途：解释哪件事、画面承担哪一步
输出：assets/S01/S01_BG01_v01.png，具体像素，RGB或RGBA
已有参考：实际文件与参考用途；无参考时说明是否先准备身份图
中文制作说明：具体主体、构图、动作、区域与回传要求
可复制提示词：填写完整描述，不保留变量；视频另附英文版本
负面约束：与本镜有关的身份漂移、裁切、文字、背景或动作错误
验收：实际画面、文件格式、尺寸/透明、身份与相邻镜衔接
```

## 前置输入与制作产物

图片、视频、录屏、实际数据、用户提供的动作/字幕文件属于需盘点的输入。TSX、JS、场景DSL、依据审查后图像生成的标注，以及本期配音/字幕/缓存通常是制作阶段产物；缺少它们不能提前写动画或编造时间。若用户已经提供这些文件，则盘点、检查并在正确阶段复用。

剪映默认ST-001～004及实际原生配置。Remotion与两种白板要走浏览器路线；经用户同意具体镜头后才可预渲染交付剪映，不能把所需实现误称为“用户还缺一个视频”。JS环境效果也不自动转成原生。

执行细节见[素材契约](../frame_and_asset_contract.md)、[制作阶段](../production_stages.md)、[分镜工程](../shot_video_guide.md)和[外部视频回传](../external_video_workflow.md)。此目录是素材指南，不新增CLI生成命令或付费平台API。
