# ST-001 · 单图动画：素材准备

先执行[共用缺素材规则](README.md)及[手绘出图规则](../image_prompt_rules.md)。每镜以一张完整主图为主体，仅注明全屏模式或绘本模式；环境特效可选。用户指定图型时，主图按原图型生成完整图文画面，不擅自拆成无字插画和后期文字。

用户要求绘本类视频时，必须读取[绘本制作指南](../picturebook_guide.md)。默认采用纸页留白、完整插画居中、下方居中短句；每页一张无字完整图，多个ST-001镜头形成故事。浏览器与剪映使用同一套页面素材；不默认左右图文解释栏，不要求先把图片做成视频。横竖画幅分别安排图像区域与字幕安全区，缺图按页交付具体提示词和实际参考图。

## 所需素材与格式

|素材|必要性|交付格式|要求|
|---|---|---|---|
|完整主图|必需|PNG优先；可解码JPG/WebP|主体完整、构图符合镜头，运动/放大边界有余量|
|背景|条件必需|主图背景，或已选纯色/纸色色值；纹理需要PNG|绘本模式可用程序色底，不额外强制生成背景图|
|标题/说明|可选|准确文案；本期MD/TXT内容记录|指定图型时遵从图文出图规则并逐字检查；没有图型且需可编辑时后期制作，不重复叠加图内已有文案|
|角色/场景参考|需要保持一致时必需|实际PNG/JPG/WebP|准备主图之前确认身份与视觉方向|
|环境特效用图|仅选了实际需要的特效时|透明PNG等已实现契约|列明遮挡、区域与时间；没有素材需求的程序效果不要求用户补图片|

全屏图按全片尺寸和放大需求准备；绘本插画按插画区域准备，主图不要求铺满屏幕。关键帧不需要预先输出一堆相似图片，这仍是单图；角色若需实质动作，应选其他已确认类型。

## 文件与配置

推荐`assets/S01/S01_IMG01_v01.png`。四秒/30fps示例的config片段：

```json
{
  "asset": "assets/S01/S01_IMG01_v01.png",
  "fit": "contain",
  "region": [0, 0, 1, 1],
  "keyframes": [
    {"at_frame": 0, "region": [0, 0, 1, 1]},
    {"at_frame": 119, "region": [-0.03, -0.03, 1.06, 1.06]}
  ]
}
```

绘本模式改为明确的插画region，并在镜头layers增加text；当前没有`mode=绘本`通用字段，不发明开关。示例说明字段用法，正式构图必须审看可见主体。

## 缺素材提示词

完整主图缺失时，有图型先按手绘Skill的原图型与图文规则交付提示词；下列无字模板只适用于未指定图型且已确认拆分文字的方案。分别按选定模式交付一个完整提示词：

```text
生成一张用于{S01内容目的}的{全屏/绘本}手绘插画。画布{宽×高}，{本期画风具体线条与质感}，配色{具体色值与分工}。场景{时间、地点、环境}，主体{身份、服装、道具与姿态}。画面必须表达{具体事件/概念}。
构图：{主体位置、景别和留白}。{全屏：说明裁切和镜头推近后的安全边界；绘本：说明插画区域，不画标题区、正文和页面UI}。保持{实际参考图中的身份和视觉特征}。输出一张完整图，{明确PNG尺寸}。不要拆图，不要添加字幕、水印或无关文字；不要裁断{本镜关键部位/物件}。
```

若身份图缺失，先追加身份参考提示词：同一人物的全身静态形象、固定脸型/服饰/道具、清晰正面或所需侧面，按本期风格绘制；交付后审看，再用于主图。不默认生成未经用户选择的新角色。

## 验收与输出路线

- 主图可解码，构图、比例、主体与文字区符合方案；检查最终缩放/裁切后仍完整。
- 一张主图的相机运动不被描述为人物已产生动作；可选效果不遮挡讲解重点。
- 剪映可用已适配位置/缩放/透明度关键帧；任意旋转、JS环境效果不能直接当作已支持原生能力。原生转场/特效另按[剪映规则](../jianying_output_guide.md)配置，不要求生成一个视频来替代。
