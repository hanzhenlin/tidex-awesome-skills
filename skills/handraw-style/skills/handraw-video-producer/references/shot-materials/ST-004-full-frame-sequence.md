# ST-004 · 全图有限帧动画：素材准备

先执行[共用缺素材规则](README.md)。多张图都包含完整背景与人物；按确定顺序/停留时间切换，不拆sprite、不自动补帧。

## 所需素材与格式

|素材|必要性|交付格式|要求|
|---|---|---|---|
|完整场景图片序列|必需，至少两张|同尺寸PNG优先；JPG/WebP须实际可解码|同人物、同场景、同画风；变化只服务动作或可见结果|
|首帧/身份/场景参考|需要一致性时必需|实际PNG/JPG/WebP|先审看首帧；后续图按同参考和动作表生成|
|动作阶段表|必需说明|MD/JSON；最终写入frames|每图内容变化、顺序、hold_frames、接触与反馈|
|字幕/标签文案|可选|准确文案|默认后期制作，不让不同帧的字形随机变化|

所有帧保持一致像素尺寸、机位、主体大小与关键位置；除非方案确需机位变化，不让背景、脸型、衣服随每帧漂移。每张是完整画面，PNG不要求透明。

## 文件与配置

推荐`assets/S04/S04_FULL_001_v01.png`等。四秒/30fps三图示例：

```json
{
  "frames": [
    {"asset": "assets/S04/S04_FULL_001_v01.png", "hold_frames": 30},
    {"asset": "assets/S04/S04_FULL_002_v01.png", "hold_frames": 45},
    {"asset": "assets/S04/S04_FULL_003_v01.png", "hold_frames": 45}
  ],
  "fit": "contain"
}
```

hold_frames总和必须等于镜头帧数。此例为一次性完整图序列，不新增自动循环/插帧接口。绘本跨页/不同场景换图属于多个ST-001镜头，不自动当成同场景有限帧动作。

## 缺素材提示词

先列动作表：建立状态、行动或接触、结果与反应。按实际需求选择图数，不机械固定三张。

```text
首帧：生成{统一尺寸}的完整手绘画面，{画风、色板、地点、光照、固定机位}。主体{完整身份和服饰/道具}正在{初始情境}，为{本镜内容目的}服务。构图固定{人物坐标/大小、地面、物体位置与可见边界}。整张图包含背景和人物，不分层、不透明。不添加字幕、水印或无关文字。
```

```text
第{编号}帧：使用实际上传的{审查通过首帧及身份参考}作为一致性依据，输出相同{像素尺寸}的完整画面。保留相同角色脸型、衣服、配件、背景布局、机位、主体尺度、光线和色板。本帧只改变{准确的姿态、物体状态和场景响应}，表现{动作阶段}；{接触点和可见结果}必须清楚。不要重设计场景、随机变换视角、添加/删去无关物件或改写文字。不得拆成透明人物，也不要把多帧拼成一张联系表。
```

每个缺帧独立写提示词并交付参考，不用“同上”替代完整动作与身份说明。首帧尚缺时先完成首帧任务；不能让用户上传不存在的参考。

## 验收与输出路线

- 逐图检查身份、构图、手脚/道具/遮挡和画面变化；按停留时间审看切换是否表达事件。
- 图片不可重复充当不存在的动作帧；不能宣称已生成平滑连续动画。
- 剪映可原生排列完整图片片段，保留每图停留时间；原生转场作用于末图到下一镜首图，不能把几张图强制融合或变速。
