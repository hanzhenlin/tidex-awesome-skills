# ST-007 · SRT 版白板动画：素材准备

先执行[共用缺素材规则](README.md)。以完整插画的语义分区控制连续落墨与添彩；需要图像、分区意图与实际字幕时序相互对应。

## 所需素材与格式

|素材|必要性|交付格式|要求|
|---|---|---|---|
|完整待绘制插画|必需|PNG优先；完整非透明纸底画面|线条清晰、背景干净、适量强调色；不使用照片/复杂厚涂冒充清晰线稿|
|语义分区意图|必需说明|MD/分区表；已有标注可提供JSON|哪些物体依次出现、讲解意义、保护区及完成后保留|
|已有字幕|已有时盘点；未有时制作阶段生成|UTF-8 SRT或实际timing_cues|真实时间、顺序与文本；镜头局部时间从0起|
|渲染分区标注|制作阶段通常生成；已有时先审核|UTF-8 annotation JSON|canvas、elements、sequence、region、cue_index、reveal/保护区|
|身份/构图参考|需要时必需|实际PNG/JPG/WebP|使角色、物体与全片视觉统一|
|手/笔图|选择自定义手时需要；默认可不用用户提供|符合本期实现的PNG|尺寸、朝向、尖端锚点与实际引擎契约先核对|

引擎使用config.image对应的完整成稿；线条清晰与少量平涂颜色可以在同一PNG中，不强制交付一份黑白图和另一份彩色图。额外线稿可以作为参考，不能宣称当前自动在两个文件间切换。

## 文件与配置

推荐`assets/S07/page.png`；已有字幕放`assets/S07/local.srt`，标注制作后放`work/S07/annotation.json`。已有SRT的config片段：

```json
{
  "image": "assets/S07/page.png",
  "annotation": "work/S07/annotation.json",
  "srt": "assets/S07/local.srt"
}
```

没有实际字幕时使用align_narration=true且不填写伪造的srt。先审查画面与数据，制作阶段生成用户指定服务配音、真实work/timing.json，再对齐区域；既有手绘语义顺序不会因代码缺失而授权提前制作。

标注结构示例，坐标基于原图1920×1080，字幕cue_index从0起，sequence从1连续：

```json
{
  "canvas": {"width":1920,"height":1080},
  "elements": [
    {
      "id":"cup", "sequence":1, "cue_index":0,
      "region":{"x":150,"y":150,"width":400,"height":400},
      "reveal":{"protectedRegions":[{"x":0,"y":900,"width":1920,"height":180}]}
    }
  ]
}
```

有实际cue时适配器填写startMs/durationMs；无cue且已批准使用无旁白固定演示节拍时，可明确填写真实设计节拍，并不称其为实际配音时间。多个分区串行，每区至少3帧且不超镜头；不能裁切/换图后沿用旧坐标。

SRT格式示例（仅说明文件语法，不是本期已生成的字幕时间）：

```srt
1
00:00:00,000 --> 00:00:02,000
先把桌面整理好。
```

跨镜头的全片SRT先按镜头范围对齐/拆成局部cue；不能把全片后段时间直接当镜头内时间。

## 缺素材提示词

完整插画缺失时先为画面提供提示词，语义分区描述不要求图像模型画出坐标框：

```text
生成{具体宽×高}的完整手绘白板插画，用于按字幕解释{内容目的}。背景为{本期纸色}，{具体清晰深色线条、笔宽感和少量强调色}，无摄影质感、复杂阴影或满幅纹理。
构图按{顺序概念}安排{独立物体/人物}：{每个对象的姿态、关系、区域和准确相对位置}。各对象轮廓完整，语义区域尽量不相交；{未来绘制区域与字幕保护位置}保持清晰分隔。身份参考为实际提供的{参考及用途}。
输出一张包含全部最终可见对象的完整PNG，不画分区边框、编号、箭头说明文字或字幕，不提前把讲解文案写入图中。不要裁断主体、密集细碎噪点、写实照片/厚涂、高饱和大面积填色或任意增加物件。
```

标注缺失时在画面审核后安排制作任务：依据真实PNG尺寸，量取region与protectedRegions，按已确认语义顺序编sequence；有实际字幕后映射cue_index与时间。不能用语言模型猜坐标替代实际看图。

字幕缺失时不让Flow生成假字幕或猜时间；待全部画面齐备后用指定配音服务生成实际配音和字幕。用户已有录音但无字幕时，需要实际转写/对齐流程，不用插画提示词解决。

## 验收与输出路线

- 实际审看清晰线条、有限强调色、分区可分离、身份与构图；标注canvas必须匹配原图尺寸。
- 检查后续区域不提前露出、保护区正确、连续笔迹后添彩、绘制顺序与字幕语义一致。编辑代理仅规划，不代表实际落墨效果。
- 剪映默认不支持此实现原生；用户同意具体镜头后才可预渲染，不能把普通图片淡入当SRT白板。
