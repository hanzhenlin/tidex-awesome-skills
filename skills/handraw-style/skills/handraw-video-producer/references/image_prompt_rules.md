# 视频图片沿用手绘出图规则

视频用途不改变图片出图规范。写提示词或出图前，读取[手绘提示词 Skill](../../handdraw-style-prompter/SKILL.md)，按其当前的风格、图型、配色、模式和参考图规则执行；固定后缀只从该 Skill 读取，不维护另一套文本。

## 用户指定图型时

- 图型决定生图画面的构图与文字结构，不是仅供后期排版参考的标签。先读取所选图型的原始提示词，按其要求完整拼接；标准图型采用图文模式及原文固定后缀，例外按手绘 Skill 执行。
- 视频导演可先设计并交用户确认逐镜内容、文案与尺寸。组装图文提示词时保留用户主题原文与已确认内容，不另改情节；明确文案要求，按手绘 Skill 的语义生成规则执行。
- 不因ST-001、绘本、剪映文字可编辑或字幕分层而擅自把指定图型改成无字插画。用户明确要求拆分或无字时，才按实际指令与输出能力设计素材契约。
- 图文模式的可复制提示词不包含风格/图型/色彩编号、参考图路径、上传操作或参考隔离段；参考文件及用法单独交付。风格特征按当前模型能力记录选择，不能另造风格描述。
- 独立身份参考板、透明sprite等有专门用途的输入，按其自身契约准备；不能把参考板当成最终图型主图，也不能把它们的无字要求套到指定图型的最终画面。

## 合成与验收

已生成完整图文卡的ST-001主图以整张图片进入镜头，region与画幅按实际卡片计算，不再叠加相同标题、短句或重建一套页面。文字已在图片内，不能称为可编辑文字；旁白字幕仍独立处理，检查文字逐字准确、画内字号、字幕遮挡与关键帧裁切。文案需要修改时改图或重新生成，保留原件。

没有指定图型时，可按已确认方案使用无字插画与独立文字；这是默认素材组织方式，不覆盖明确图型。更改已确认的页面组织时更新方案与素材记录，使用用户真实纠正/确认作为依据，不伪造授权。
