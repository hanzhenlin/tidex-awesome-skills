# 知识视频导演 v3.2

与 [视频制作总控](../handraw-video-producer/SKILL.md) 共用 [分镜工程](../handraw-video-producer/references/shot_video_guide.md)、[阶段检查](../handraw-video-producer/references/production_stages.md)、[素材契约](../handraw-video-producer/references/frame_and_asset_contract.md)。

先明确受众已有知识、唯一学习目标、事实证据与看完可采取的行动。来源核对先于表达；生成画面不作为事实或真实操作证据。组织开头问题/具体例子/概念解释/可见因果/结论，不套固定业务模板。

方案设计前先与用户确定输出路线：浏览器成片或剪映草稿，记录output_target。浏览器路线可选择七类分镜；剪映默认只用ST-001～004并检查实际原生效果，不自动引入JS或网页预渲染。两者分别由[浏览器制作](../handraw-browser-producer/SKILL.md)和[剪映制作](../handraw-jianying-producer/SKILL.md)执行，共用本导演流程。用户同意具体镜头预渲染时，才设计例外并由总控记录，不把auto当同意。

先全片视觉与运动方向，再逐镜：id、目的、帧范围、口播锚点、ST类型、画面、动作、素材来源与理由、接触反馈、镜头衔接。用具象隐喻解释抽象概念，明确隐喻与事实边界。角色意图→行动→环境结果→角色反馈，动作不只装饰。节拍为建立情境→行动解释→结果与交接；时长随内容与实际配音安排。

共享目录仅ST-001～ST-007：单图、视频、背景＋透明素材、全图有限帧、Remotion、simo白板、SRT白板。图片、数据、真实录屏、外部生成视频按目的选择，同一知识主题可用不同镜头组合。文字/高亮/图表/镜头等在类型内部编排，不另建顶层分类。AI可定义本期新类型，验证后用户决定是否共享。

ST-001单图动画可选择全屏模式或绘本模式；绘本模式为背景、插画区与文字区的编排。关键帧与环境特效可选，按内容及实际实现选择；这两种模式只注明在ST-001，不新增版式画廊或扩充其他模式。

用户选择绘本叙事表达知识时读取[绘本制作指南](../handraw-video-producer/references/picturebook_guide.md)。每页用一个具体事件或因果环节解释内容，完整插画居中，短句位于下方；事实信息保持准确，故事隐喻边界明确。浏览器成片或剪映草稿均可制作这种布局，按所选路线设计动画，不把左右图表解释栏当默认绘本。多页为多个ST-001镜头，不新增分类；故事短句和旁白字幕分别设计。

方案完整交用户确认；确认后提供视频提示词和所需实际参考图、收集全部画面。所有必需素材经技术和实际画面审查通过才配音/动画/预演/合成。阶段记录恢复续作，不把已有素材当已确认方案。SRT白板未有字幕时先审核线稿与数据，制作阶段用实际配音字幕对齐，不估时、不提前渲染。

逐镜使用[分镜素材准备目录](../handraw-video-producer/references/shot-materials/README.md)中的对应文档，列出所需素材、格式及缺项。确认后为每个可生成的缺失素材写具体完整提示词并交付实际参考图；事实、操作记录、原件与配音时间缺失时提供采集清单。不能用泛用提示词代替本镜任务，也不能把TSX、绘制编排或配音后字幕误列为开工前必须提供的画面素材。

审片检查：动作是否解释概念；文字是否保留事实；接触与反馈同步；主体身份与首尾连续；后续白板区域不提前显露；截图/录屏是否可读；每镜目的是否实现。技术验证与用户审美接受独立，不承诺视频受欢迎或生成质量通过。

剪映方案交付为独立草稿与实际素材包，镜头对照、字幕策略、声音与本机字体/特效条件在说明列明。包内检查通过仅证明素材、路径和结构完整；剪映应用打开与实际导出、动态审美仍另行审查，见[本地整合](../handraw-video-producer/references/jianying_local_integration.md)。
